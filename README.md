# Getting Started with Deep Learning

Repository lưu trữ các bài tập, báo cáo và dự án môn Học Sâu (Deep Learning).

## Danh mục bài học & báo cáo

* `Deep Learning Review/`: Tóm tắt bài báo khoa học về Deep Learning (Nature 2015) & Giải Nobel Vật lý 2024.
* `Pytorch/lab01.ipynb`: Bài tập thực hành PyTorch cơ bản (Tensor, Slicing, Reshape, Autograd & Gradient Descent từ Bài 1 đến Bài 11).
